# 集装箱寻宝

在微信开发者工具中直接打开本目录，即可运行 `game.js` 对应的小游戏。项目使用现有微信小游戏原生入口；观察、竞价和开箱是分开的页面。

微信小游戏玩法验证版。每箱明确分成三个阶段：观察线索 → 决定出价或放弃 → 拍下后逐件开箱出售。卖出收入减去拍下花费，就是本场现金盈亏。内容和电脑预算在观察开始前确定，进度保存在设备本地。

按 V0.3 接入三种开门信息层级、三主题各五组加权预设（每箱五件物品）、手电和放大镜、六场还款和逾期抵押、查封降档，以及免费整理旧物。开拍后不会按余额或出价修改内容、对手预算和上限。

对手根据公开线索的内容池期望值、主题偏好、开门形态及本场预算估价，出价后等待约 1.2 秒。双方总出价最多八次，到顶由领先者成交。拍前不给精确售价，结算后可打开物品明细复盘。

经营页面可购买设备（每场各一次），达到 750/900 金币永久解锁摄影/维修主题，余额达到 2000 可进入进阶档（起拍 300、加价 60、价值三倍，款额从 600 起）。这些未定门槛为原型暂定值。抵押品不能使用，补齐欠款后自动赎回；查封保留图鉴记录与主题。

当前运行美术为新生成的卡通货柜、两名对手各六种表情和货物图集，存放于 `assets/resources/art`；旧写实图集不再加载，也不进入小游戏发布包。

保留开门、举牌、成交、物品弹出和少量出售金币反馈。观察与开箱在动效结束后停止空转；竞价表情与等待反馈按约 30 FPS 更新。暂停或切到后台后停止动画和对手倒计时，返回时恢复剩余时间。

现阶段仍是规则原型，未迁移 Cocos Creator。数值分布和长期债务压力尚未通过验证，不能视作最终平衡或上架版本。

出价、揭晓和结算包含音效；可在暂停菜单关闭，设置保存在本地。

观察页显示货柜、线索和设备；竞价页显示对手、价格与出价/放弃；开箱页逐件处理物品。顶栏显示金币与还款倒计时，结算单独显示现金盈亏、对手反应和饰品。

图鉴按乐队、摄影和维修主题展示已有藏品：好品可选择出售换金币，或放弃收入收藏；图鉴支持分类、分页、物品详情和抵押状态。未收藏条目保持隐藏。旧存档中的收藏仍会显示。

## 运行

在微信开发者工具中导入本目录，项目类型选择小游戏，使用自己的小游戏 AppID 或测试号运行。

## 代码和素材

- `game.js`：小游戏入口。
- `src/app`：应用与场景生命周期。
- `src/platform`：微信平台接口。
- `src/features/auction/game.js`：状态流转、存档和玩家操作。
- `src/features/auction/data`：货柜内容与图鉴数据。
- `src/features/auction/rules`：开场内容/对手生成与还款处理，独立于界面。
- `src/features/auction/render`：Canvas 基础绘制、货柜、角色、图片裁切与动效。
- `src/features/auction/scene.js`、`menu.js`：场景与菜单路由。
- `src/features/auction/views`：观察、竞价、开箱、结算、设备与还款等页面。
- `assets/resources/art`：当前运行使用的货柜、角色和物品素材。
- `images/container_treasure_assets`：合并后的两批原始素材，`素材映射.csv` 为新映射；原始压缩包及新包解压副本保留在 `images` 下。该目录不进入小游戏发布包。

旧素材与生成原图保留在工作区，已通过打包忽略规则排除；当前玩法和美术仍需微信开发者工具及真机试玩调整。
