# 素材放置说明

请把素材放到这个 `assets` 文件夹下，按下面的用途分类。不需要一次准备齐全，已有素材先放进对应文件夹即可；名字不确定也可以先保留原文件名，并告诉我哪个文件是什么。

| 文件夹 | 放什么 |
| --- | --- |
| `images/scenes/` | 港口、仓库、拍卖场等背景，以及完整场景参考图 |
| `images/containers/` | 集装箱、箱门、货箱内部等图片 |
| `images/items/` | 自行车、乐器盒、纸箱、相机、工具等物品图片 |
| `images/characters/` | 拍卖员和电脑对手的角色图片 |
| `images/ui/` | 按钮、面板、金币图标等界面图片 |
| `audio/music/` | 背景音乐 |
| `audio/effects/` | 落槌、开箱、揭晓等音效 |
| `references/` | 风格参考图和说明文件，仅供开发参考 |

建议图片使用 PNG（需要透明背景时尤其适合），音频使用 MP3 或 WAV；请保留素材原始文件。素材接入前会确认用途、尺寸与授权。`references/` 内的参考文件应避免放入最终发布包。

素材包已有自己的下划线命名规则，新增文件优先参照 `images/container_treasure_assets/文件映射.txt`。直接放入文件后请告诉我用途；图片不会自动进入游戏，需要在代码中完成映射并检查显示效果。
